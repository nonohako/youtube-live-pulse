# 라이브 펄스

지정한 YouTube 채널을 백그라운드에서 확인하고 라이브 또는 예약 방송을 Chrome으로 자동 여는 Windows 트레이 앱입니다.

기본 채널로 아래 주소가 등록되어 있습니다.

`https://www.youtube.com/channel/UCtKtCiaWRz-d3EZn2xd1mdA`

## 포함된 기능

- Windows 로그인 시 백그라운드 자동 실행(설치본)
- 15~300초 간격의 라이브 상태 확인
- 라이브 시작과 예약 방송 발견 시 Chrome 자동 열기
- 채널 URL, `@핸들`, 채널 ID로 채널 추가
- 새 동영상과 새 게시물 알림
- YouTube의 새 `/videos`·`/streams`·`/shorts` 카드 구조를 함께 읽는 영상·라이브 감지
- LIVE/OFFLINE/확인 상태 인디케이터
- 구독자 수와 로컬 누적 추이 차트
- 구독자 차트 클릭 시 기간별 상세 차트, 선형 추세선, 고점·저점과 일별 추세 표시
- 일일 증가량, 성장률 추이, 증가세 둔화, 3일 모멘텀과 기간 전후반 기울기 변화 분석
- 오늘 미완료 데이터 제외 및 날짜 클릭·드래그 구간별 누적 증감, 평균 증가량·성장률 분석
- 구독자 차트를 모든 수집 시각 또는 날짜별 마지막 값으로 표시하는 설정
- 조회수 전용 탭: 썸네일 목록, 채널 필터, 영상 검색, 상세 차트 바로 열기
- 최대 4개 영상의 누적 조회수·기간 증가량 비교
- 구독자·조회수 차트에서 날짜/수집 시각 기준 즉시 전환, 마지막 선택 기간 유지
- 최근 영상별 조회수 기록과 기간별 상세 차트, 추세선, 휠 확대·축소
- 채널별 과거 구독자 기록 `.xlsx` 가져오기와 기존 날짜 보호
- Windows 트레이 상주, 중복 팝업·중복 알림 방지
- 선택적 YouTube Data API 키 지원

## 24시간 통계 수집

선택적으로 Fly.io와 Upstash를 연결하면 PC가 꺼져 있어도 서버가 구독자 수와 최근 영상 조회수를 1분마다 기록합니다. 앱 설정에서 연결 파일을 가져오면 서버의 최근 30일 기록을 받아 로컬에 계속 보관합니다. 기존 로컬·엑셀 기록은 보존됩니다. 서버 설정과 비용·할당량은 [클라우드 배포 안내](cloud/README.md)를 참고하세요.

## 개발 실행

```powershell
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" install
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" start
```

일반적인 npm 설치에서는 `npm install`, `npm start`만 사용하면 됩니다. 위의 긴 명령은 현재 개발 환경의 npm 경로 우회용입니다.

## 테스트와 Windows 설치 파일

```powershell
node --test
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" run build
```

완성된 설치 파일은 `dist/LivePulse-Setup-1.9.0.exe`에 생성됩니다. 설치 후 앱 설정에서 “Windows 로그인 때 자동 실행”이 켜져 있으면 다음 로그인부터 숨김 상태로 트레이에서 시작합니다.

## 자동 업데이트

설치본은 앱 시작 약 8초 후 GitHub Releases에서 새 버전을 확인하고, 이후 4시간마다 다시 확인합니다. 새 버전은 백그라운드에서 내려받으며 다운로드가 끝나면 재시작 설치 여부를 묻습니다. “나중에”를 선택하면 앱을 종료할 때 설치됩니다.

새 버전을 배포하려면 `package.json` 버전을 올려 커밋한 뒤 같은 버전의 태그를 푸시합니다.

```powershell
git tag v1.8.0
git push origin v1.8.0
```

GitHub Actions가 테스트, Windows 설치 파일 빌드, Release 및 업데이트 메타데이터 게시를 자동으로 처리합니다.

## 과거 구독자 기록 가져오기

등록 채널의 구독자 영역을 눌러 상세 차트를 연 뒤 **엑셀 기록 가져오기**를 선택하세요. `.xlsx` 파일 안에서 `날짜`와 `전체 구독자` 열을 찾아 해당 채널 이력에 추가합니다. `합계`와 `평균` 행, `신규 구독자` 열은 계산에 사용하지 않습니다.

- 가져온 기록 시각은 각 로컬 날짜의 00:00입니다.
- 같은 날짜의 기록이 앱에 이미 하나라도 있으면 기존 값을 유지하고 건너뜁니다.
- 파일 안에 같은 날짜가 반복되면 마지막으로 읽은 유효한 값을 사용합니다.
- 형식이 다른 행은 제외하며, 완료 후 추가·유지·제외 건수를 화면에 표시합니다.

## 데이터와 제약

- API 키가 없어도 YouTube 공개 채널 페이지와 공식 RSS 피드로 동작합니다.
- YouTube Data API 키를 설정하면 공식 채널 통계와 여러 영상의 공개 조회수를 한 요청으로 보강합니다. API 키는 로그인 권한이 아니며, 다른 채널의 공개 구독자 수는 API를 사용해도 YouTube 정책에 따라 세 자리 유효숫자로 반올림됩니다.
- API 키가 없어도 `/videos`, `/streams`, 공개 영상 페이지와 공식 RSS 피드로 새 영상·라이브를 감지하고 조회수를 수집합니다.
- 최근 영상의 조회수는 5분마다 확인하며, 숫자가 바뀌거나 6시간이 지나야 새 표본을 저장합니다. 영상 행의 **조회수 추이**를 눌러 7일·30일·90일·1년·전체 차트를 열 수 있습니다.
- 조회수 기록은 v1.8.0 설치 뒤 앱이 실제로 확인한 시점부터 쌓입니다. YouTube는 과거 시점별 조회수를 소급 제공하지 않으므로 설치 전 추이는 복원할 수 없습니다.
- 구독자 이력은 앱을 설치한 시점부터 로컬에 쌓이며, 보유한 과거 기록은 채널별 `.xlsx` 가져오기로 보강할 수 있습니다.
- 설정의 **구독자 차트 표시 기준**에서 모든 수집 시각을 그대로 보거나 날짜별 마지막 값만 한 점으로 볼 수 있습니다. 이 설정은 표시만 바꾸며 저장된 원본 기록은 삭제하거나 합치지 않습니다.
- 성장 분석은 완료된 날짜별 마지막 측정값을 기준으로 하며, 측정일이 비면 증가분을 경과 일수로 나눕니다. 오늘 값은 원본 차트에만 표시하고 성장 분석과 증가량 차트·선택 구간 계산에서는 제외합니다. 기간의 첫날은 화면 밖 직전 마감값을 기준으로 증감을 계산합니다.
- YouTube Data API에는 커뮤니티 게시물 조회 항목이 없습니다. 게시물 감지는 공개 채널 페이지 구조를 읽는 실험 기능이며 YouTube 페이지 변경이나 로그인/연령 제한에 따라 일시적으로 실패할 수 있습니다.
- “실시간” 감시는 푸시가 아닌 설정된 간격의 폴링입니다. 기본값은 30초입니다.

앱 데이터는 Electron 사용자 데이터 폴더의 `live-pulse.json` 파일에만 저장됩니다. API 키도 해당 로컬 파일에 저장되므로 공유 PC에서는 입력하지 않는 편이 안전합니다.
