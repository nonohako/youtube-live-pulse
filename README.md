# 라이브 펄스

지정한 YouTube 채널을 백그라운드에서 확인하고 라이브 또는 예약 방송을 Chrome으로 자동 여는 Windows 트레이 앱입니다. C#(.NET 10)과 WebView2로 만든 개인용 포터블 앱이며, 이 폴더 하나에 프로그램과 데이터가 모두 들어 있습니다.

## 사용 방법

- 실행: 바탕 화면의 **라이브 펄스** 바로가기 또는 `app\LivePulse.exe`를 더블클릭합니다. 이미 실행 중이면 기존 창이 열립니다.
- 창을 닫아도 트레이에서 계속 감시합니다. 완전히 끄려면 트레이 아이콘 → **종료**를 누릅니다.
- 폴더 옮기기(예: D 드라이브): 트레이에서 종료한 뒤 폴더째 옮기고, 새 위치의 `app\LivePulse.exe`를 한 번 실행합니다. Windows 시작 항목과 바탕 화면 바로가기가 자동으로 새 위치로 바뀝니다.

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `app\` | 실행 파일. 다시 빌드하면 통째로 교체됩니다. |
| `data\` | 채널·구독자·조회수 기록(SQLite)과 자동 백업 2개, 화면 설정, 오류 기록. **지우지 마세요.** `data\legacy\`에는 예전 Electron 버전의 마지막 데이터가 압축 보관되어 있습니다. |
| `native\`, `src
enderer\` | 소스 코드 |
| `cloud\` | 24시간 통계 수집 서버(선택) |

데이터는 1시간마다(그리고 라이브를 열기 직전에) 자동 백업됩니다. 앱이 강제 종료되거나 DB가 손상돼도 다음 실행 때 자동으로 되돌리거나 최신 백업으로 복구합니다.

## 포함된 기능

- Windows 로그인 시 백그라운드 자동 실행
- 15~300초 간격의 라이브 상태 확인
- 라이브 시작과 예약 방송 발견 시 Chrome 자동 열기
- 채널 URL, `@핸들`, 채널 ID로 채널 추가
- 새 동영상과 새 게시물 알림
- YouTube의 새 `/videos`·`/streams`·`/shorts` 카드 구조를 함께 읽는 영상·라이브 감지
- LIVE/OFFLINE/확인 상태 인디케이터
- 구독자 수와 로컬 누적 추이 차트
- 구독자 차트 클릭 시 기간별 상세 차트, 선형 추세선, 고점·저점과 일별 추세 표시
- 일일 증가량, 성장률 추이, 증가세 둔화, 3일 모멘텀과 기간 전후반 기울기 변화 분석
- 오늘 미완료 데이터 제외 및 날짜 클릭·드래그 구간별 누적 증감, 평균 증가량·성장률 분석
- 구독자 차트를 모든 수집 시각 또는 날짜별 마지막 값으로 표시하는 설정
- 조회수 전용 탭: 썸네일 목록, 채널 필터, 영상 검색, 상세 차트 바로 열기
- 최대 4개 영상의 누적 조회수·기간 증가량 비교
- 구독자·조회수 차트에서 날짜/수집 시각 기준 즉시 전환, 마지막 선택 기간 유지
- 최근 영상별 조회수 기록과 기간별 상세 차트, 추세선, 휠 확대·축소
- 채널별 과거 구독자 기록 `.xlsx` 가져오기와 기존 날짜 보호
- Windows 트레이 상주, 중복 팝업·중복 알림 방지
- 선택적 YouTube Data API 키 지원(공식 채널 통계·영상 조회수 일괄 조회)
- 트레이 메뉴: 창 열기, 지금 새로고침, 로그인 시 자동 실행, 종료

## 24시간 통계 수집

선택적으로 Fly.io와 Upstash를 연결하면 PC가 꺼져 있어도 서버가 구독자 수와 최근 영상 조회수를 1분마다 기록합니다. 앱 설정에서 연결 파일을 가져오면 서버의 최근 30일 기록을 받아 로컬에 계속 보관합니다. 기존 로컬·엑셀 기록은 보존됩니다. 서버 설정과 비용·할당량은 [클라우드 배포 안내](cloud/README.md)를 참고하세요.

## 하루 한 번 외부 백업

설정의 **하루 한 번 외부 백업**에서 폴더를 고르면 기록 DB를 하루 한 번 압축해 저장하고 최근 3일치만 남깁니다. Google Drive 데스크톱 앱의 폴더를 고르면 그 앱이 켜져 있을 때만 구글 드라이브에 올라갑니다.

### 구글 드라이브에 직접 백업(드라이브 앱 불필요)

설정의 **구글 드라이브에 직접 백업**을 연결하면 앱이 하루 한 번 드라이브의 `라이브 펄스 백업` 폴더에 직접 올리고 최근 3일치만 남깁니다(오래된 것은 드라이브 휴지통으로). Google Drive 데스크톱 앱은 켜 두지 않아도 되고 설치하지 않아도 됩니다. 앱은 자기가 만든 파일에만 접근하는 권한(`drive.file`)만 받습니다.

처음 한 번만 Google Cloud에서 내 OAuth 클라이언트를 만들어야 합니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다(이름 예: 라이브 펄스).
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 찾아 **사용**을 누릅니다.
3. **Google 인증 플랫폼(OAuth 동의 화면)**에서 앱 이름과 내 이메일을 넣고 대상은 **외부**로 만듭니다. 그다음 **대상 → 앱 게시(프로덕션으로 푸시)**를 누릅니다. 테스트 상태로 두면 연결이 7일마다 끊깁니다. `drive.file` 권한만 쓰므로 Google 검토는 필요 없습니다.
4. **클라이언트 → 클라이언트 만들기**에서 유형을 **데스크톱 앱**으로 고르고 만든 뒤 JSON(`client_secret_….json`)을 내려받습니다.
5. 라이브 펄스 설정에서 **구글 드라이브 연결**을 누르고 그 JSON 파일을 고릅니다. 브라우저가 열리면 내 Google 계정으로 로그인해 허용합니다. "확인되지 않은 앱" 화면이 나오면 **고급 → (앱 이름)(으)로 이동**을 누르면 됩니다(내가 만든 앱이라 그렇습니다).

연결 정보는 이 Windows 사용자만 풀 수 있게 암호화되어 `data\google-drive.dat`에만 저장되고, 드라이브에 올라가는 백업 파일에는 들어가지 않습니다. 직접 백업을 쓰면 위의 외부 백업 폴더는 비워 두어도 됩니다. **연결 해제**를 누르면 앱의 권한을 취소하며, 이미 올라간 백업은 그대로 남습니다.

## 다시 빌드하기(업데이트)

.NET 10 SDK가 필요합니다. 실행에는 .NET 10 Desktop Runtime(x64)이 설치되어 있어야 합니다(`app` 폴더는 약 5MB). Windows PowerShell에서:

```powershell
.
ative\publish-portable.ps1
```

실행 중인 앱을 안전하게 종료한 뒤 `app\`만 새로 만들고, `data\`는 그대로 둡니다. 개발용 확인 명령은 `native/README.md`와 `AGENTS.md`를 참고하세요.
